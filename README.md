# 스마트 부스 실시간 예약 시스템 2.0 (Remastered)

누구나 코딩 없이 브라우저 상에서 행사 날짜, 부스 목록, 운영 시간 및 예약 제한 정책을 커스터마이징하고, 매년 영구적으로 재사용할 수 있는 **스마트 부스 실시간 예약 플랫폼 2.0**입니다.

---

## ✨ 2.0 주요 리마스터링 특징

1. **영구적 재사용 (Dynamic Event Configuration)**
   - 더 이상 소스 코드를 직접 수정하지 않고도 행사 이름, 운영 날짜(1일~N일 자유 지정), 운영시간(시작/종료/슬롯 간격)을 동적으로 관리할 수 있습니다.
2. **시크릿 코드 관리자 포털 (Admin Portal)**
   - 헤더의 ⚙️ 관리자 버튼 또는 단축키(`Ctrl + Shift + A`)를 통해 관리자 암호(기본: `admin1234`) 입력 시 대시보드 활성화.
   - **4대 관리 기능**:
     - ⚙️ **행사 설정**: 날짜 추가/삭제, 1인당 최대 예약 횟수, 슬롯당 정원, 관리자 암호 변경
     - 🧪 **부스 관리**: 부스 이름/설명/태그 컬러 추가, 수정, 삭제
     - ⏰ **슬롯 차단**: 특정 날짜/부스의 개별 타임슬롯 예약 차단(Block/Lock)
     - 📋 **예약자 관리 & CSV 엑셀 다운로드**: 전체 예약 검색, 강제 취소, 1클릭 엑셀 내보내기 (UTF-8 BOM 지원)
3. **PC · 태블릿 · 모바일 3단 반응형 UX/UI**
   - Pretendard 고품질 폰트 및 모던 스레이트 디자인 시스템 적용.
   - 모바일 터치 친화적 탭바, 3~4열 반응형 타임테이블 그리드.
4. **Supabase Realtime 동기화 & Fallback**
   - 관리자가 설정을 변경하거나 학생이 예약/취소할 경우 접속한 모든 사용자의 화면이 즉시 업데이트됩니다.
   - DB 연결 전이거나 네트워크 미설정 시에도 기본 설정값으로 안전하게 동작합니다.

## 🚀 빠른 시작 가이드

### 1. 의존성 설치 및 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`으로 접속할 수 있습니다.

### 2. Supabase DB 설정 (새 프로젝트 연결 시)

프로젝트 루트의 `supabase_schema.sql` 스크립트를 복사하여 **Supabase Dashboard > SQL Editor**에 실행하면 모든 테이블과 Realtime 정책이 즉시 생성됩니다.

```bash
# .env 파일 생성
REACT_APP_SUPABASE_URL=https://your-project.supabase.co
REACT_APP_SUPABASE_ANON_KEY=your-anon-key
```

## 🔐 관리자 모드 접속 안내

- **기본 접속 키**: 상단 우측 `⚙️ 관리자` 버튼 클릭 또는 `Ctrl + Shift + A`
- **초기 관리자 암호**: `admin1234` (관리자 대시보드 '행사 기본 설정' 탭에서 자유롭게 변경 가능)
